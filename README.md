# Adrien Pinilla · The Garage

Personal portfolio site. The home page is an interactive garage: click a car to open a section of my portfolio, or head upstairs to the listening room for the off-the-clock side.

## Open it

Open `index.html` in a browser. No build step and no dependencies; everything is plain HTML, CSS and JavaScript.

| File | What it is |
|---|---|
| `index.html` | The garage home screen (click a car, or use the menu along the bottom) |
| `classic.html` | The same portfolio as one scrolling page ("Quick view") |
| `assets/` | The garage image (AI-rendered) and headshot |
| `mockups/` | Earlier concept mockups and the prompts used to generate the garage image |

## Controls

- Click a car, or use **← →** and **Enter**
- **Esc** or **B** goes back to the garage
- On a phone, swipe to look around and tap a car
